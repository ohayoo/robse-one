A block theme for Gutenberg-first site building, with design tokens and section patterns.

== Description ==
ROBSE ONE is a full-site editing theme for teams building and maintaining WordPress sites. It includes templates, template parts, a design system, and reusable section patterns. Optional blocks and AI features are distributed as separate plugins.

The theme does not bundle forms, custom post types, or custom blocks.

== Installation ==
1. Upload the theme ZIP through Appearance > Themes > Add New > Upload Theme.
2. Activate ROBSE ONE.
3. Open Appearance > Editor to customize templates and create pages with patterns.

== Requirements ==
* WordPress 6.6 or later
* PHP 7.4 or later
