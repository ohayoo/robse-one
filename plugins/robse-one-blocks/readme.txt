Independent Gutenberg CTA block and configurable client CMS menu profile for ROBSE ONE.

== Description ==
Provides the ROBSE CTA dynamic block, an administrator-controlled standard menu profile for non-administrators, public custom post type menu choices, and a compact dashboard editing guide.

== Installation ==
1. Upload and activate the plugin.
2. Use Settings > ROBSE ONE CMS to configure the client menu profile.
3. Insert ROBSE ONE sections from the block pattern library and the ROBSE CTA block from the inserter.

== Uninstall ==
Deleting the plugin removes its CMS menu settings. Existing posts and pages are preserved.
