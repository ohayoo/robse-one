# ROBSE ONE クイックスタート

ROBSE ONEは、テーマ・Gutenbergブロック・AI拡張を分けて使えるWordPress制作基盤です。最初はテーマとBlocksを導入し、AI機能を使う場合だけAIプラグインを追加します。

## 1. インストール

必要環境はWordPress 6.6以上、PHP 7.4以上です。

1. 管理画面の「外観 > テーマ > 新規追加 > テーマのアップロード」から `ROBSE-ONE-Theme.zip` をアップロードして有効化します。
2. 「プラグイン > 新規プラグイン > プラグインのアップロード」から `ROBSE-ONE-Blocks.zip` をアップロードして有効化します。
3. AIを利用する場合だけ `ROBSE-ONE-AI.zip` もアップロードして有効化します。

## 2. ページを作る

固定ページを新規作成し、ブロックエディターのパターン一覧から「ROBSE ONE セクション」を選びます。ヒーロー、特徴、サービス、料金、FAQ、お客様の声、問い合わせ案内のほか、クリニック・建設・飲食・採用向けの業種セットを挿入できます。パターンを入れた後は、文章・画像・リンクをサイトに合わせて編集してください。

「ROBSE CTA」ブロックはブロックインサーターから追加できます。テーマを切り替えても、ブロックプラグインを有効化していれば保存済みのコンテンツを維持できます。

## 3. 制作会社向けCMSモード

「設定 > ROBSE ONE CMS」で、管理者以外に表示する標準メニューを選べます。公開中のカスタム投稿タイプを選択すると、クライアント用メニューへ追加できます。変更を保存してもユーザー権限そのものは変わりません。プラグインが追加する他の管理メニューも制御しません。

## 4. AIページ案を使う

1. 「設定 > ROBSE ONE AI」でOpenAI APIキーと利用可能なモデル名を設定します。
2. 「ROBSE ONE AI ページ案」で事業やページの内容を入力し、外部送信への同意を確認して生成します。
3. 生成したタイトルと文章を確認・編集し、「下書きとして保存」を選びます。
4. WordPressの固定ページ一覧から下書きを開き、事実関係や表現を確認してから公開します。

入力文はOpenAI APIへ送信されます。個人情報・機密情報・第三者の非公開情報を入力しないでください。API利用料はAPIキーの契約者に発生します。機能を有効にする前に、サイトのプライバシーポリシーを更新してください。詳しくは [AIデータ取扱いメモ](AI-PRIVACY.md) を確認してください。

## 5. 更新前後の確認

更新前にサイトとデータベースをバックアップします。更新後はトップページ、固定ページ、投稿、問い合わせ導線、管理画面を確認してください。サイトエディターでテンプレートを保存している場合は、データベース上の編集内容がテーマファイルより優先されることがあります。

詳細なインストール・削除手順は [INSTALL.md](INSTALL.md)、確認履歴と残作業は [QA.md](QA.md) を参照してください。
