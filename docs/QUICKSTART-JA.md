# ROBSE ONE 導入・更新ガイド（0.3.0）

テーマとプラグインは別々に使えます。まずテーマだけで固定ページを作り、連絡先リンクや CMS の案内が必要なら Blocks、文章の構成案が必要なら AI を追加します。

## 新しくサイトを作る

1. `dist/robse-one-0.3.0.zip` を「外観 → テーマ → 新規追加 → テーマのアップロード」から入れる。
2. 「固定ページ → 新規追加」で、パターン「完成見本 — デザイン制作会社」または業種別パターンを挿入する。タイトルなしの「ページ本文」テンプレートも選べる。
3. 仮の名称・営業時間・料金・実績・画像を実際の情報へ置き換える。見本には架空である旨を明記している。
4. 連絡方法を設定する。Blocks の「ROBSE 連絡先リンク」なら実際の電話番号・メールアドレスを入力する。ボタンが `#contact` へ移動する場合は、そのブロックの HTML アンカーを `contact` にする。フォームで受け付ける場合はフォームプラグインのブロックを入れ、送信と通知メールを確認する。
5. 固定ページを公開し、「設定 → 表示設定」でホームページに選ぶ。**その後「外観 → ROBSE ONE 導入ガイド」で固定ページ方式を選び、保存する。**
6. 以後、文章は「固定ページ」から編集する。編集者ロールの担当者も、サイト全体のテンプレートへ入らずに変更できる。Blocks のダッシュボードからも直接開ける。

## 既存サイトを更新する

更新前にサイトとデータベースをバックアップする。テーマ更新だけではトップの編集方式は変わらない。固定ページ方式は明示的に選ぶ。従来方式へ戻しても固定ページ本文は消えない。

保存済みのカスタムフロントページテンプレートは優先し、上書きしない。その場合はサイトエディターで内容を確認する。テンプレート側に「投稿コンテンツ」を残してから引き継ぐ。

## 配色・ロゴ・公開前確認

サイトエディターの「スタイル」で標準・エディトリアル・ミッドナイトを選ぶ。共通パレットとカードの角丸は連動するが、以前保存されたブロックの個別指定は保持する。任意の色変更後は読みやすさを確認する。ロゴはヘッダーのサイトロゴブロックから設定する。

公開前に実情報への置換、ボタン・発信・メール・フォーム、スマホメニュー、更新担当者の保存を確認する。フォーム機能とメール配信はテーマにも Blocks にも含まない。CMS モードはメニューを隠すだけで、権限やページ内レイアウトを固定しない。

## AI を使う

AI の ZIP は `dist/robse-one-ai-0.3.3.zip`。API キー・モデルを管理者が設定し、入力の外部送信に同意して構成案を作る。確認・編集して下書き保存する。公開は自動で行わない。セクションは見出し・文章・余白つきの標準ブロックになり、テーマを変えても文章は残る。画像選び・業種専用機能・フォームの接続は別途行う。
