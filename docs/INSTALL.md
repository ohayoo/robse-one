# インストール・更新・削除

対応環境は WordPress 6.6 以上、PHP 7.4 以上。最新版の手順は [QUICKSTART-JA.md](QUICKSTART-JA.md) を参照。

## インストール

テーマ `robse-one-0.3.0.zip`、任意の Blocks `robse-one-blocks-0.3.0.zip` と AI `robse-one-ai-0.3.3.zip` は、それぞれ管理画面でアップロードする。ZIP は案件フォルダの `dist/` にある。AI の設定は「ROBSE ONE AI → AI 設定」で行う。

## 更新と戻し方

更新前にファイルとデータベースを保存する。同名のテーマ／プラグインへ上書き更新する。トップ表示の方式は更新だけでは変わらず、カスタムテンプレート・既存本文・ブロック属性を保持する。固定ページ方式は導入ガイドから明示的に選び、同じ画面で従来方式へ戻せる。

テーマを旧版に戻す場合はバックアップの ZIP を再アップロードする。固定ページ本文は残るが、旧版では従来テンプレートの内容を表示する。サイトエディターに保存済みのテンプレートはテーマファイルより優先される。新しい連絡先ブロックを使ったサイトでは Blocks を旧版に戻す前に、標準の電話・メールリンクへ置き換える。

## 削除

テーマを切り替えてからテーマを削除する。Blocks／AI は無効化後に削除できる。削除時は CMS 設定や API キー等の設定を削除する。固定ページと AI の下書きは残る。Blocks を削除すると独自の CTA／連絡先ブロックの表示は止まるので、事前に標準ブロックへ置き換える。
