# インストール・更新・削除

## 対応環境

- WordPress 6.6以上
- PHP 7.4以上
- ROBSE ONE Blocks、ROBSE ONE AIはテーマと独立して有効化可能
- AIページ案機能を使う場合は、サーバーから api.openai.com へのHTTPS接続が必要

## インストール

1. WordPress管理画面の「外観 > テーマ > 新規追加 > テーマのアップロード」から ROBSE-ONE-Theme.zip をアップロードし、有効化します。
2. 「プラグイン > 新規プラグイン > プラグインのアップロード」から ROBSE-ONE-Blocks.zip をアップロードし、有効化します。
3. AI機能を使う場合のみ ROBSE-ONE-AI.zip もアップロードし、有効化します。
4. CMSメニューを整える場合は「設定 > ROBSE ONE CMS」を開きます。
5. AIを使う場合は「設定 > ROBSE ONE AI」でAPIキーとモデルを設定します。管理者権限が必要です。

## 更新

更新前にサイトとデータベースのバックアップを取ります。ZIPをアップロードする際に同名テーマ・プラグインの既存版を置き換えます。更新後、トップページ、投稿、固定ページ、管理画面を確認してください。テンプレートをサイトエディターで保存している場合、WordPressのデータベースに保存された編集内容がテーマファイルより優先されることがあります。

## 削除

テーマを切り替えてからテーマファイルを削除します。Blocks / AIプラグインは無効化後に削除できます。プラグイン削除時、CMSモード設定とAI設定（APIキーを含む）は削除します。AIで作成したページ下書きは削除せず、サイトに残します。
