# ROBSE ONE AI：サイト運営者向けデータ取扱いメモ

ROBSE ONE AIのページ案作成を実行すると、画面の依頼文がWordPressサーバーからOpenAI APIへ送られます。生成結果はユーザーが編集・確認した後に、WordPressの固定ページ下書きとして保存されます。

## 実装上の扱い

- 送信前に画面上で同意チェックが必要です。REST API側でも同意を確認します。
- 依頼文はページ案作成のAPIリクエストにのみ含めます。サイト名やユーザー情報は送信しません。
- OpenAI APIキーはブラウザーへ出力しません。wp-config.php の ROBSE_ONE_AI_API_KEY 定数を優先し、未設定ならWordPressオプションに保存します。
- Responses APIには store: false を指定します。これはAPIリクエスト上で応答保存を無効にする指定です。OpenAI側のデータ処理、ログ、保持条件を含む詳細は、利用するアカウントとサービス条件をサイト運営者が確認してください。
- API利用料はAPIキーの契約者に発生します。プラグインは費用を見積もったり上限管理したりしません。

## サイトのプライバシーポリシーへの追記例

以下をサイトの運営者・プライバシーポリシーに合わせて編集してください。法務確認済みの文面ではありません。

> 当サイトの管理者は、ROBSE ONE AIによるページ案作成を利用する場合、入力した依頼文をOpenAI APIへ送信します。入力には個人情報、機密情報、第三者の非公開情報を含めないでください。生成結果は管理者が確認したうえで当サイトの下書きとして保存します。API利用に伴う費用や外部サービスでのデータ処理については、当サイト運営者が管理します。

AI機能を使わない場合、ROBSE ONE AIプラグインをインストール・有効化する必要はありません。

## 対応バージョンに関する設計判断

WordPress.orgのPlugin CheckはWordPress 7.0以降のAI Client利用を推奨します。ROBSE ONE AIはWordPress 6.6以降をサポートするため、6.6・6.7でも利用できるOpenAI Responses APIへの直接リクエストを採用しています。これは対応範囲を維持するための意図的な実装です。
