# ROBSE ONE

WordPressブロックテーマと独立した機能プラグインで構成する、制作会社向けサイト制作基盤の初期版です。

## 構成

- themes/robse-one — FSEテーマ、デザイントークン、テンプレート、セクション／業種パターン
- plugins/robse-one-blocks — 独立した CTA・連絡先リンクブロック、クライアント編集ガイド、CMSメニュー設定
- plugins/robse-one-ai — 同意付きページ案生成と固定ページ下書き作成

## できること

- WordPress 6.6以上、PHP 7.4以上のブロックテーマ
- トップ、固定ページ、投稿、アーカイブ、検索、404のテンプレート
- 8種以上のセクションと、クリニック・建設・飲食・採用のスターターパターン
- 色、文字、余白、角丸などのデザイントークン
- テーマを切り替えても残るサーバーレンダリングCTAブロック
- CMSモードで管理者以外に見せる標準メニューと公開カスタム投稿タイプを選択
- AI案は画面で確認・編集し、明示操作後に下書きとして保存

## 導入

配布用ZIPと詳細手順は docs/INSTALL.md を参照してください。テーマ、Blocks、AIは必要に応じて別々に導入できます。AI機能の設定・データ取扱いは docs/AI-PRIVACY.md を確認してください。

初回の設定と基本操作は [日本語クイックスタート](docs/QUICKSTART-JA.md) を参照してください。

## 現在の制限

CMSモードはメニューの表示を調整する機能です。権限設定は変更せず、他のプラグインが追加する管理メニューも制御しません。AI機能はOpenAI APIキーとAPI利用料が必要です。フォーム、SEO、Schema、クラウド配布、自動更新は含みません。AI生成APIの外部実キーによる動作確認は行わず、ローカルの模擬応答で確認しています。
